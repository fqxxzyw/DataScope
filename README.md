# DataScope · 数据工作台 + ContextMap

## v1.4：文本语义探索与数据集文件夹

ContextMap 已集成到左侧「文本语义探索」，使用同一应用和 EXE。原始文本 → 可配置预处理 → 分词 → 词频 / N-Gram → TF-IDF → 共现网络 / 向量 / 余弦相似度，所有计算在本机完成。

[ContextMap 完整学习文档、架构与真实截图](docs/CONTEXTMAP.md) · [Live Demo](https://fqxxzyw.github.io/DataScope/) · [Windows Release](https://github.com/fqxxzyw/DataScope/releases/latest)

支持文件夹中的 train / dev / test / class（含 clasee）/ stop_word；先核对用途与编号，分别导出三份 fastText，绝不混合训练与测试。动画提示放在对应操作旁。

## v1.2：先看数据，再开始分析

1. 支持一次选择多个文件，先检查前 8 行、列数、分隔符与表头，再确认分析。
2. 无表头时生成 Text / Number / Label 等唯一列名，红色标题注明“系统补充”；绿色表格保留读取值。自动判断不确定时保留首行，允许手动切换。
3. TXT 不再一律当作单列；支持自动识别制表符、逗号等。需要保留整行时选择纯文本模式。
4. 多文件可按列名追加、按行连接正文与标签，或按键关联标签字典。按行关联需确认顺序且行数相等；按键关联拒绝右表重复键，保留主表未匹配行并报告数量。
5. 分析后先显示数据表，再确认正文/标签用途。数字与字母都可以作为分类标签；fastText 导出支持数字标签。
6. 已确认的正文/标签自动带入训练格式映射。缺标签时可以继续添加文件；支持 fastText、BERT 单句/句对、回归、多标签、NER、Seq2Seq、指令、对话、DPO、QA 等已有适配器。
7. 居中弹窗、统一主题下拉菜单、圆角玻璃质感，保留键盘与系统缩放支持。

关联当前文件时使用上次导入的原始工作副本，不含之后的数据整理；界面会明确提醒。原文件不会覆盖。单文件最大 50 MB、单次选择总计 100 MB、组合结果最大 200 万单元格。Excel/Parquet 仍需先转 CSV/JSONL。

# DataScope · 数据集体检与 EDA 工作台

**让数据，先说清自己。** 一个纯浏览器、本地优先的无代码数据分析与整理工具，采用空间分层与 Liquid Glass 风格界面。支持中文文本、表格统计、规则驱动任务适配器与可复现数据集划分。

无后端、无账号、无 AI API、无追踪。数据不会上传；你的判断与原始数据始终保留。

## 启动

需要 Node.js 22.12+ 或 24 LTS（开发验证 Node 24）。

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 http://localhost:4173）。

```bash
npm run lint
npm run test
npm run build
npm run preview
```

生产文件位于 `dist/`，可部署到任何静态托管。`base: './'` 支持 GitHub Pages 仓库子路径。源应用含 ES modules / Worker，不能直接双击 `index.html`；导出的 HTML 报告可以直接双击。

## 能做什么

- 一页式分析工作台，手动指定标签、预测与特征列；自选 X/Y/分组/聚合图表；分类混淆矩阵与回归误差分析。
- 22 类可组合数据整理操作：条件筛选、选列/改名、缺失处理、按列去重、文本规范化与替换、派生列、分组聚合、数值缩放/裁剪、编码、排序与抽样。预览后应用到内存工作副本，可撤销三次或恢复原始数据；保存 CSV/JSONL、特征+标签与操作配方。

- CSV / TSV / TXT / JSON / JSONL / fastText / 两列 CoNLL-BIO 导入；表头与分隔符可选。
- 字段规则推断和手动改型、数值 describe、Unicode 文本长度、缺失标记、精确重复组、类别分布与目标不均衡。
- 直方图、箱线图、横向词频、按标签词频对比、Pearson 热力图与配对样本数。
- 可解释健康评分、问题定位、问题 CSV 导出、建议复核清单。
- 17 种输出适配器，显式字段映射、校验、预览、可选清洗及处理 manifest。
- 随机 / 分层 / 分组 / 时间划分；比例与随机种子；子集 EDA、标签比例对比、重复和实体泄漏审查；CSV 和划分 manifest。
- 自包含 HTML / 完整统计 JSON 导出；最近五份本地历史摘要；深浅主题、键盘快捷键、响应式、减少动态效果。

## 使用顺序

1. 导入文件或体验 Demo。检查导入格式、编码和字段类型。
2. 在「类别分布」显式设置 Target。未选 Target 不进行不均衡扣分。
3. 在「问题洞察」查看证据和建议，必要时导出具体记录。
4. 在「格式与处理」选择目标任务，逐项映射源字段。清洗默认关闭。校验失败会阻止导出。
5. 在「数据集划分」选方法、比例、种子和审查字段，检查子集图表与风险提示，再导出。
6. 导出报告用于复核。历史不保留全量原始表；再次查看具体行需重新导入。

**数据整理会更新当前工作副本**：应用后重新分析，格式转换和划分使用当前工作副本。格式适配器中的可选处理仅作用于导出副本，不隐式覆盖工作集。各子集需特定模型格式时，可逐个导入并转换。缩放、统计填补等用于训练时应先划分，仅在训练集拟合参数。

## 架构与目录

```text
src/
  engine/       纯函数：解析、统计、推断、文本、问题、适配器、划分、导出
  engine/analysis.worker.ts  原始数据所有者及类型化消息协议
  components/   图表、预览、字段检查、分析页面、格式处理与划分
  store.ts      Zustand 会话状态、Worker 生命周期与请求 ID
  storage.ts    IndexedDB 最近五份摘要
  App.tsx       页面导航、导入、快捷键和导出面板
  style.css     空间玻璃主题、响应式与动效降级
public/examples/  合成示例，非真实用户数据
docs/          完善后的提示词、规则说明、支持矩阵、验收记录
```

Worker 承担读取解析、分析、查询、转换、划分。取消时终止 Worker；重新导入清理旧请求。主线程只渲染至多 50 行/页，不创建几万行 DOM。分页是此版的大表渲染策略，并非无限虚拟滚动。

## 统计规则

见 [算法与限制](docs/ALGORITHMS.md)。评分为：

`round(100 − 50 × 空白单元格率 − 30 × 重复副本率 − 10 × 目标严重不均衡指示量 − 10 × 指定类型无效单元格率)`。

结果最低为 0。疑似缺失字符串、IQR 异常和长短文本不单独扣分；这些规则依赖上下文。分数不是模型适用性或业务数据质量的认证。

## 格式与任务

见 [格式支持矩阵](docs/FORMATS.md)。**不存在通用“BERT 文件格式”**：本项目导出明确命名的记录字段，具体训练代码仍需 tokenizer 和数据集映射。不自动执行模型词表、SMOTE、PCA、训练、自动标注、语义纠错或不明格式推断。

## 隐私与安全

- 不请求在线分析服务，不加载外部字体或 CDN，不包含追踪 SDK。
- IndexedDB 中的摘要包含实际唯一值/词频，可能仍然敏感；可以在首页清除历史。
- localStorage 仅保存主题、设置、导航偏好，不保存原始 Dataset。
- HTML 报告转义不可信内容；图表 tooltip 使用 Canvas rich text；CSV 导出防公式注入（可能为危险前缀增加单引号，请在下游读取时知悉）。
- 导出的报告、处理副本、划分文件属于用户主动导出，分享前自行复核。

## 已知限制

- UTF-8 为主；文件保护上限 50 MB / 200 万单元格。超过上限会明确拒绝；不是流式无限数据引擎。
- 执行阶段进度是真实阶段估计，不冒充逐行精确百分比。
- JSON null 与缺键映射为空白；嵌套值保留 JSON 字符串。通用 JSONL 导出保留表格字符串类型。
- 相关性最多前 20 个 Numeric 字段；分布表最多前 100 类；默认词频 Top 100。所有上限在界面标明。
- 日期按明确 ISO / YYYY-MM-DD / YYYY/MM/DD 规则；带时间但不带时区的值按浏览器本地时区处理。
- 文本长度是 Unicode 码点，不是 grapheme cluster 或模型 token 数。分词依赖浏览器 ICU 实现。
- 分层按一个字段完整值分层，多标签视为标签组合；不支持迭代多标签分层、group-stratified 联合优化或近似文本查重。
- 组划分优先保证实体不交叉，比例可能偏差。时间相同的记录可能跨边界；请结合实体审查。
- 建议为规则提示，不能识别语义错误。格式校验通过不代表数据适合训练。
- 已在 Chromium 浏览器完成部分流程检查；完整验收状态见 docs/VALIDATION.md，尚未完成所有新增整理操作的端到端验证。

## v1.3 操作图解与类别列表

若 `class.txt` 每行只有类别名，而 `train.txt` 是正文与数字编号，请选择 **类别列表映射**，无需手工制作编号列。确认从 0 或 1 开始后，程序通过编号查找类别，并保留原编号。`train/dev/test` 分开处理，停用词表不追加进样本。

所有整理操作及输出格式均有独立图解：悬停或点击问号，查看绿色输入、红色规则与蓝色结果；提示位于具体操作旁。关联后的字段带来源文件名。Windows 图标由仓库内脚本确定性生成，不需要额外图像工具。

## v1.4 文件夹导入

点击“打开数据文件夹”或拖入数据目录。文件用途卡片分别展示 train、dev、test、class（兼容 clasee）、stop_word 等候选，未知文件默认不参与。每个样本文件可单独指定正文和标签列；确认后共用类别映射和可选停用词配置，分别预览并下载 fastText ZIP。不会把数据集、类别表、停用词表混成一张表。

帮助问号跟随具体操作，不再需要到统一入口查找。文件夹导入最多 40 个支持格式文件、合计 100 MB；拖入目录最多遍历 1000 个条目。原文件不修改。
