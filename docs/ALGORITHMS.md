# 算法、契约与边界

## 类型推断

按优先级检查全空 → 布尔 → 严格日期 → 字段名指示 ID / 前导零 ID → 数值比例（默认 90%）→ 文本字段名 → 标签字段名 → 小类别数（≤20）或低唯一值比（≤5%）→ 类 ID → 文本。唯一值比例本身不足以把连续数值误判为 ID。用户可改型；混合数值字段会提示复核。布尔默认 true/false/yes/no，0/1 为数值，避免自动改变数值含义。

## 数值统计

有效值为严格十进制/科学计数法且 `Number.isFinite`。统计时按最大绝对值缩放，缓解均值和方差中间求和溢出；无法有限表示的标准差返回 null。分位数是 `(n−1)p` 索引线性插值。标准差采用 n−1，单样本定义为 0。直方图最多 20 个等宽 bin（常量列一个）。IQR 用 Q1−1.5IQR / Q3+1.5IQR；箱线图须线展示 min/max，图示明确说明。

Pearson 成对去除无效值后缩放中心化；零方差和 n<2 返回 null，显示有效 n。最多前 20 个 Numeric 字段，全量有效样本统计。

## 文本与缺失

字符按 Unicode code point，不是字形簇或模型 token。长度统计包括空白记录；长文本为严格大于配置分位数，短文本为 ≤ 阈值。Intl.Segmenter 在设备本地分词，英文字母小写，支持基础停用词。缺少 API 时回退中文单字与英文单词并提示。

空字符串或仅空白记为空白；null / None / NaN / N/A / NA / undefined 等字符串单列为疑似标记，不修改。JSON 的真实 null 或缺键在表格投影时映射为空白。

## 重复与问题

完整原始字符串数组 `JSON.stringify` 作键，避免简单分隔符连接碰撞；Map 避免原型键污染。每组额外副本 n−1，问题受影响行是组内所有成员。十一类 issue 共享 severity、column、affectedRows、ratio、description、suggestion、rows。提示只建议复核，不隐式清洗。

## 评分

`round(max(0, 100 − 50m − 30d − 10b − 10i))`。

m=空白格/总格；d=额外重复副本/总行；b=用户显式选择分类目标且 max/min 类别比≥阈值；i=Numeric/Date/Boolean 指定类型无效格/总格。界面列出未四舍五入的扣分项。高评分不排除严重业务问题。

## 自选图表与预测评估

用户选 X、Y、分组、count/mean/sum，支持分类柱状、数值直方、箱线、散点、数值折线、交叉频数热力与缺失图。数值关系统计用全量有效对；绘图最多 5000 点与 10 个组，类别图最多选定 10/20/50/100 类。截断范围和统计 n 明确展示。

真实列与预测列由用户手选。分类精确比较字符串标签，最多 100 类；提供 accuracy、macro/weighted F1、precision/recall/F1/support 和混淆矩阵。零分母记 0，宏平均使用真实/预测标签并集；不自动将概率阈值化。回归提供 MAE/RMSE/R² 和预测−真实残差，常量真实列 R² 未定义；极端误差超出数值范围则报错。

## 数据集划分

随机由 32 位 LCG 驱动 Fisher–Yates，同输入同种子可复现。比例使用最大余数法分配整行。分层对每个标签值独立配额；小类别无法覆盖每个子集时提示。按实体分组先固定随机打散同大小组，再按组大小递减，分配给剩余目标容量最大的子集，不拆组。随机重复绑定使用相同组算法。时间划分按有效日期升序，保持原始次序打破并列。

所有行恰好一个归属，输出 0-based 数据行索引（不含表头）。跨集精确重复和选定键重叠独立检查。组完整性优先可能牺牲比例；时间优先可能牺牲重复组绑定。多标签按组合分层，不是 iterative stratification。

## 历史与 Worker

Worker 持有原始表，消息带请求 ID。读取与分析阶段进度只是阶段百分比，不声称精确扫描行数。取消终止 Worker 并拒绝未完成请求。IndexedDB `datascope` / `reports`，keyPath=createdAt，每次写后仅留最新五份报告，字段为 Report；不保存 Dataset.rows。报告包含字段唯一值摘要、词频和索引，仍可能敏感。localStorage 仅偏好。

50 MB 与 200 万单元格为明确保护限制。此版全量内存计算，不声称大文件流式处理。部分唯一值、长度排序和分组有 O(n log n) / O(n) 成本。


### v1.1 分层划分全局配额
先用最大余数法计算三个子集的全局整数目标；为各类别分配比例的向下取整部分，再按类别欠额、剩余全局容量分配余量。类别顺序和样本顺序由同一个种子确定。保证总量精确、零比例子集为空、不丢样本、不重复分配；稀有类别仍可能无法覆盖每个子集。与 v1.0 的独立类别取整相比，同一种子下的成员可能改变，应记录软件版本。
