DataScope v1.2.0 · Windows 10/11 x64

- 安装版：`*-nsis.exe`；免安装版：`*-portable.exe`。
- 导入先预览原始数据，确认表头和分隔符后再分析；分析首页以数据表开场。
- 自动补充列名并标色说明，修复分隔 TXT 被误读为单列的问题。
- 多文件追加、按行关联正文与标签、按键关联标签字典，提供组合预览和匹配统计。
- 数字/字母标签均可用于 fastText；确认的正文/标签自动带入导出映射，提供缺标签文件导入引导。
- 增加文本分类整理配方，保留先预览后应用及原文件不覆盖机制。
- 修复弹窗居中，统一浅色/深色下拉菜单和圆角外观。

自动化验证包括算法与导入关联测试、完整无表头 TXT/多文件标签/fastText 流程、四种窗口宽度布局检查，以及 Windows 打包程序四档显示缩放的导入导出检查。

程序未签名，Windows 首次运行可能显示未知发布者。关联现有数据使用原始导入副本（不含之后的整理操作）；默认不静默进行按行关联。按键连接为保留主表的多对一连接，右表重复键需先修复。
