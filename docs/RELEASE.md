请核对文件用途、正文/标签列、类别顺序及编号起点；程序按名称提供建议，不能推断类别语义顺序。停用词按词匹配，字符模式只能匹配单字。程序未签名。

## ContextMap · 内置文本语义关系探索器

从 DataScope 左侧「文本语义探索」进入，无需安装第二个应用。
支持粘贴、TXT / CSV / TSV 和沿用当前数据；原数据预览后选择正文与标签。
本地中文 / 英文分词、可配置 Pipeline、词频 / KWIC、N-Gram 滑动窗口、
可解释 TF-IDF、共现热力图 / D3 网络、稀疏文本向量、余弦相似度和标签对比。
统计 CSV / JSON 导出，原文默认不保存也不导出；最近 5 个统计摘要保存在 IndexedDB。
耗时计算使用 Web Worker，支持取消，最多 10,000 文档、100 条相似度矩阵。

## 数据标注 Annotation Workspace

新增一级标注工作台：项目、文件 / 文件夹扫描、稳定 ID、动态标签管理、快捷键、
自动保存、跳过 / 撤销、搜索筛选、随机抽查、标签分布、历史、项目备份 / 恢复、
新增数据关联、JSON / JSONL / CSV / fastText / BERT ZIP 与原有划分衔接。
标注工作副本和进度保存于本机 IndexedDB，不修改原始数据。单标签分类已实现；
NER、多标签界面、AI 预标注和模型训练不在本次范围。
