DataScope v1.3.0 · Windows 10/11 x64

- class.txt 类别列表专用映射：明确选择从 0 或 1 开始编号，展示编号与类别名称，确认后按编号查表；拒绝越界、空值和重复类别。
- train/dev/test 分别关联类别表，原数字编号保留；stopwords 不作为样本或类别表自动追加。
- 关联字段使用“文件名 · 列名”，例如 train.txt · Text、class.txt · Label。
- 操作旁提供问号图解：绿色输入、红色规则或第二张表、蓝色结果，支持悬停、键盘聚焦及点击；支持减少动态效果。
- 覆盖全部 22 种整理操作、17 种输出适配器、关联方式和划分方法，并提供可搜索操作图解。
- 为 EXE、安装程序、窗口与网页设置统一 DataScope 图标，替换默认 Electron 图标。

使用 class + train：同时导入 → 点击“配置样本 + class 类别列表” → 核对编号起点与类别顺序并确认 → 分析 → 确认正文与标签 → 格式与处理选择 fastText → 校验预览并导出。数字标签也可以不映射名称直接使用。

已验证用户提供的 180000 条训练、10000 条验证及 10000 条测试样本均可按 10 类列表映射并生成 fastText；用户数据不包含在源码或发布包中。自动化检查包括单元测试、界面流程、多窗口宽度和 Windows 打包程序四档显示缩放验证。

程序未签名，首次运行可能显示未知发布者。按类别行号映射依赖训练数据约定，程序不能推断类别顺序是否正确；需用户确认。原文件不被覆盖。
