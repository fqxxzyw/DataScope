DataScope Windows 桌面版（Windows 10/11 x64）。

- `*-nsis.exe`：安装版，可选择安装目录。
- `*-portable.exe`：免安装版，直接运行。
- `SHA256SUMS.txt`：下载校验。

保留本地离线分析、数据整理、格式转换和数据集划分能力。
修复长文件名/字段名、窄窗口、表单及卡片的溢出问题。
分层划分新增全局整数配额，避免多个小类别独立取整导致验证集/测试集比例失衡。

发布前自动执行算法测试、四种窗口宽度布局检查，以及真实 Windows 打包程序在 100% / 125% / 150% / 200% 缩放下的启动、导入、页面切换和导出测试。

此版本未购买代码签名证书，Windows 可能显示未知发布者提示。桌面版历史摘要保存在本机应用数据目录，与浏览器版独立；原始文件不会被覆盖。
