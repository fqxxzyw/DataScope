# DataScope · 完善后的实现提示词

你是一名负责交付的前端与数据工程师。完整实现 DataScope 本地数据集体检与 EDA 工作台，交付可运行、可测试、可构建的 GitHub 项目。不要只给原型，不调用 LLM、在线分析或第三方追踪，不伪造指标。

## 目标与优先顺序

1. 保真读取原始记录，给出可解释的质量分析与可行动建议。
2. 用明确语法识别数据容器，使用用户字段映射确定任务，不把模型名当作文件格式。
3. 所有清洗默认关闭，转换只生成副本；失败记录必须明确报错，不能静默丢弃。
4. 支持可复现数据集划分并提供泄漏风险审查。
5. 用 visionOS 空间层次与 Liquid Glass 视觉语言承载功能：通透层叠、柔和光晕、清晰边缘、圆角、充足留白。交互有弹性回弹和磁性悬停，同时支持键盘、深浅主题和 reduced-motion。

## 工程约束

React + strict TypeScript + Vite + Tailwind CSS + ECharts + Papa Parse + Web Worker + Zustand + IndexedDB + Vitest + Lucide。分析算法保持纯函数；Worker 保存原始记录，主线程仅接收摘要、分页、预览与必要导出。不得将完整原始数据写入 localStorage / IndexedDB，不上传用户数据。

## 数据契约

支持 CSV、TSV、TXT、JSON 对象数组、JSONL、fastText 行首标签、两列 CoNLL/BIO。表格分隔符与表头可手动选择。保留空白样本；重复/空表头唯一化；不规则列数和未闭合引号报错。UTF-8 替换字符提示编码风险。设 50 MB / 200 万单元格保护上限，显示原因而非崩溃。自动识别仅依据已定义结构；不确定时给出手动选项。

## 统计契约

- 空白与疑似缺失字符串独立计数，后者不自动转换。
- 数值使用严格十进制/科学计数法有限值；空白不转为 0，保留前导零标识符。
- 日期验证真实日历，不把任意数字传入宽松日期解析后当日期。
- 重复副本数等于每组数量减一；问题行与导出包含完整重复组。
- 数值分位数使用线性插值，标准差用 n−1；常量/空列相关性未定义。
- Pearson 使用成对有效值，显示 n；解释相关不等于因果。
- Unicode 文本长度按码点；分词用本地 Intl.Segmenter，缺失时有明确回退。
- IQR、超短与超长文本都只是筛查信号。不得自动断言错误或强制删除。
- 不均衡仅针对用户选定 Target，缺失标签独立统计；小样本附提示。
- 所有阈值集中配置，用户更改后重新分析。
- 评分展示每项扣分及分母，不使用神秘 AI 分数。

## 功能与可视化

总览、分页数据预览、字段检查、缺失、重复、类别分布、文本长度和高频词、按标签词频比较、数值直方图/箱线图、Pearson 热力图、问题清单与复核清单。图表包括 hover 信息、主题、响应式适配；高基数显示数量上限，并明确统计是否全量。

## 处理适配器

实现通用 CSV/TSV/JSONL/TXT、fastText 单/多标签、BERT/HF 单句与句对记录、多标签、回归、CoNLL/NER、Seq2Seq、指令、对话 messages、DPO、抽取问答、检索三元组。

每个适配器声明字段要求并校验。模型 tokenizer、special tokens、padding、truncation、chat template 留在训练端配置；不可用普通分词假装完成 BERT 编码。JSON 数组长度、BIO/BIOES/BILOU 转移、回归数值、QA 字符偏移、DPO 答案不同、对话角色等都写成规则。罗列不支持的二进制或专用格式，不宣称穷尽所有情况。

可选去首尾空白、NFC、合并空白、移除映射必需字段为空的行、按转换记录去重。先给输入/输出/移除/失败计数与预览，再导出副本及处理 manifest。避免 CSV 公式注入；HTML 完全转义不可信字符串。

## 划分

随机、单标签分层、实体分组、时间顺序；可设 train/validation/test 比例与种子。所有行恰好归属一个子集。随机可将完全重复组绑定；分层与组绑定冲突时拒绝而不是虚假保证。检查稀有类、空子集、无效时间、缺失分组键、跨集精确重复和指定文本/实体键重叠。展示各子集样本、比例、缺失、重复、类别分布；输出 CSV 与索引/参数 manifest。提醒只在训练集拟合预处理。

## 存储与导出

IndexedDB 保存最近五份分析摘要；摘要可能包含实际唯一值和词频，说明敏感信息并可清除。历史只读，具体行/重新分析必须重新导入。HTML 报告自包含、双击打开；JSON 保存统计与参数；问题 CSV 保留字段并加入不冲突的 issue 字段。

## 验收

实际运行 npm install、npm run lint、npm run test、npm run build。测试解析异常、空列、混合格式、大数、中文/emoji、重复哈希安全、HTML/CSV 注入、全部适配器关键路径、固定种子与行划分不丢失/不交叠。浏览器验证 Demo、目标设置、词频、问题定位、导出、格式转换、划分、历史、主题与键盘操作。未验证的浏览器或性能规模必须如实注明。

交付完整源码、锁文件、许可证、CI、示例、架构与算法解释、格式矩阵、运行方式、验证记录及已知限制。用户已授权创建 fqxxzyw 账户的公开仓库并提交，不提交真实数据、凭据、个人身份信息或临时构建缓存。

## 用户追加的交互修订（优先于原始多页布局）

采用一页 EDA 工作台，概览、角色选择、自选图表、预测评估、数据预览及可折叠深入分析在同页。侧栏只放工作台、字段与训练配置、格式处理、数据集划分、设置。真实标签、预测列、输入特征、ID、时间列均由用户指定；不要只按自动猜测固定分析。

增加动态 X/Y/分组/聚合选择，可生成柱状、直方、箱线、散点、折线、交叉频数热力和缺失图。按明确任务提供混淆矩阵/分类指标或回归误差，不将概率列或模型名称猜成标签。字段和图表是可组合操作，适配器枚举不是交互自由度的替代品。
